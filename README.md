# Oluwaseun O. Ajayi — Academic Website

Personal academic website for Oluwaseun O. Ajayi, PhD candidate in Chemistry at the University of Georgia, specializing in bioanalytical chemistry, enzymology, structural biology, and computational modeling.

Live site: https://oluwaseun-o-ajayi.github.io/my-website/

## Contents

- **Home** — bio, research focus, and links to key profiles
- **CV** — summary curriculum vitae
- **Full CV** — complete honors, memberships, professional service, and conference history
- **Publications** — peer-reviewed journal articles, manuscripts, and book chapters
- **Projects** — research project summaries
- **News** — recent updates and presentations
- **Elsewhere** — links to academic, professional, and personal profiles across other platforms
